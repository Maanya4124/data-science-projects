
# Academic Management System

## Overview
This project involved developing a console-based academic management application using C++ to help students organise and track their academic activities.

## Objective
To create a simple application that allows students to manage assignments, tests, practice questions and study materials.

## Tools and Technologies
- C++
- Object-Oriented Programming

## Project Work
- Developed a console-based application.
- Implemented features to track assignments and tests.
- Included functionality for practising questions.
- Enabled students to upload and manage study material.

## Key Learnings
Strengthened programming and problem-solving skills while gaining practical experience in developing an application using C++.
