
# Gold Price Time Series Analysis

## Overview
This project involved applying statistical methods to analyse gold price data and identify trends and patterns over time.

## Objective
To explore historical gold price movements using time series analysis techniques.

## Tools and Technologies
- Python
- Statistical Analysis
- Time Series Analysis

## Project Work
- Explored historical gold price data.
- Analysed trends and patterns over time.
- Applied statistical methods to study price movements.

## Key Learnings
Developed an understanding of time-dependent data, trend analysis and the application of statistical techniques to financial data.
