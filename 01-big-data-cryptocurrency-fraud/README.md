
# Cryptocurrency Fraud Analysis

## Overview
This project involved analysing cryptocurrency transaction data to identify potentially fraudulent activities using Big Data analytics techniques.

## Objective
To explore transaction patterns and identify indicators of fraudulent behaviour within cryptocurrency data.

## Tools and Technologies
- Python
- EMR
- Spark
- Machine Learning Models

## Project Work
- Analysed cryptocurrency transaction data.
- Explored patterns associated with fraudulent activities.
- Applied data analytics techniques to investigate suspicious transactions.

## Key Learnings
Gained experience in working with large-scale transaction data and understanding challenges associated with fraud detection.
