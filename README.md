A collection of my academic, research and applied projects in Data Science.

Hello, I'm Maanya Raichura!

This repository brings together my academic projects, research work, and practical applications across Data Science and related fields.

Areas of Interest: Machine Learning and Deep Learning, Computer Vision and Image Processing, Data Analytics and Visualisation, Statistical Modelling and Time Series Analysis

The projects are:

- Machine Learning II: Developed and evaluated machine learning models to predict increases or decreases in stock prices using the NIFTY-50 dataset.
- Data Visualisation: Created visualisations using Python to analyse real-time data on climate and natural disasters.
- Machine Learning I: Developed a credit card fraud detection system using machine learning models. Focused on handling highly imbalanced datasets and improving model performance.
- Databases for Data Science: Designed a relational database management system for a Badminton Management System using MySQL. Implemented schema design, ER modelling, complex SQL queries and transaction handling.
- Analysis and Forecasting of Time Series: Applied statistical methods to analyse gold price trends and patterns.
- C++ Programming: Developed a console-based academic management application. A tool helpful for students to track their assignments and tests, practice questions and upload material.
