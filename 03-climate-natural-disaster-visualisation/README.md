
# Climate and Natural Disaster Visualisation

## Overview
This project involved creating data visualisations using Python to explore real-time data related to climate and natural disasters.

## Objective
To analyse and communicate patterns in climate and natural disaster data through visualisation.

## Tools and Technologies
- Python
- Pandas
- Data Visualisation

## Project Work
- Worked with real-time climate and natural disaster data.
- Processed and explored the available data.
- Created visualisations to identify and communicate patterns.

## Key Learnings
Developed practical experience in data exploration, visual storytelling and communicating insights through visualisations.
