
# NIFTY-50 Stock Movement Prediction

## Overview
This project involved developing and evaluating machine learning models to predict whether stock prices would increase or decrease using the NIFTY-50 dataset.

## Objective
To explore the use of machine learning techniques for predicting stock price movements.

## Tools and Technologies
- Python
- Machine Learning Models
- Pandas
- NumPy
- Scikit-learn

## Project Work
- Worked with the NIFTY-50 dataset.
- Explored and prepared stock market data.
- Developed machine learning models to predict stock price movements.
- Evaluated model performance.

## Key Learnings
Gained experience in applying machine learning techniques to financial time-series data and evaluating predictive models.
