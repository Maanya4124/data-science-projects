
# Badminton Management System

## Overview
This project involved designing and implementing a relational database management system for a Badminton Management System using MySQL.

## Objective
To design a structured database for managing badminton-related information and operations.

## Tools and Technologies
- MySQL
- SQL
- Entity Relationship Modelling

## Project Work
- Designed the database schema.
- Developed an Entity Relationship (ER) model.
- Implemented complex SQL queries.
- Used database transactions to manage operations.

## Key Learnings
Gained practical experience in relational database design, SQL query development and transaction handling.
